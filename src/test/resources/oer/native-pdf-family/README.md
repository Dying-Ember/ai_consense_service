# Authored native-PDF family contract fixtures

These files are synthetic contract inputs. Their PDF, glyph/raster observations,
parser output declarations, source review and full CAS were produced from authored
two-page test material without a neural model or competition original.

`authored-child-v1.json` retains the reviewed v1 business contract. `authored-child-v2.json`
and `authored-family-v2.json` were generated by the pinned v2 Python producer;
the complete two-parent source-unit summary is from Python `SourceUnits.resolve`.
They do not certify OCR quality, legal meaning, full-source coverage or pixels.

The normal Java contract, business and V14-to-V15 tests require only these authored
files. Actual v1/50, v2/4 and family/54 public wires remain ignored local evidence.
To run their additional replay suite set `CONSENSE_OER_FAMILY_REPLAY_ROOT` to the
local directory containing the four reviewed `actual-*.json` files, and run
`NativePdfSourceFamilyReplayTest`. The reader checks exact SHA256, file size and
directory containment. Without the environment variable its three tests are
explicitly skipped; no default test silently searches a developer machine.
